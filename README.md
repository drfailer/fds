## Claude Experiement

This is a fork of [FDS](https://github.com/firemodels/fds) on which we tested to use claude to rewrite the simulation using [Hedgehog](https://github.com/usnistgov/hedgehog). This is a complex exercise since FDS architecture does not directly apply to Hedgehog's paradigm. The objective is to let the AI come up with a solution with minimal guidance and see if it is able to rewrite the simulation successfully.
